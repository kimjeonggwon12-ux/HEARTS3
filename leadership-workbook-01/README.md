# 명문 리더십 교육 1회차 워크북

- `명문리더십교육_1회차_워크북.pdf` — A4 32쪽 컬러 워크북 (인쇄용)
- `src/` — 원본(HTML/CSS/이미지). 수정 후 다시 PDF로 만들려면:
  ```bash
  cd src && npm i pretendard @fontsource/black-han-sans @fontsource/nanum-myeongjo playwright
  node build.js 0 pdf   # workbook.pdf 생성
  ```

구성: 여는 글 · 교육/학습 목표 · 프롤로그(명문가) · PART1 조직문화 진단 · PART2 리더십 자가진단 ·
PART3 명문 리더의 덕목 · PART4 성장 질문 · PART5 경청과 소통(재진술·원온원) ·
PART6 구조 설계(피쉬본·PMI·5Whys·갤러리 카페/워크) · PART7 현장 적용(4주 전달 플랜·20분 모임 진행표·처방전·30일 실천표) ·
PART8 비전 캔버스·리더 선언문·2회차(10/17) 준비
